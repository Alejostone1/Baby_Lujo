# BABY LUJO · Catálogos comerciales

Catálogo digital interactivo y catálogo editorial PDF de **BABY LUJO by Joaquín RP**, generados desde una única fuente de datos.

| Carpeta | Contenido |
|---|---|
| `01_CATALOGO_DIGITAL/baby-lujo-web` | Sitio Next.js (catálogo, ficha de producto, panel `/admin`, páginas de impresión `/imprimir/*`) |
| `02_CATALOGO_PDF` | PDF de alta calidad y PDF liviano para WhatsApp (se regeneran con `npm run pdf`) |
| `03_IDENTIDAD_VISUAL` | Logotipo original, paleta y tipografías |
| `04_INVENTARIO` | Auditoría, inventario (CSV) y equivalencia de nombres de fotos |
| `05_DOCUMENTACION` | Cómo actualizar productos, regenerar el PDF y publicar |
| `_herramientas` | Scripts de la auditoría y del tratamiento fotográfico inicial |

Consulta `05_DOCUMENTACION` para el uso diario.
